# 备考教练流程

配合工作区根目录 `AGENTS.md` 使用。所有路径相对工作区根目录。
倒计时与统计用看板算，不要心算：
`powershell -NoProfile -ExecutionPolicy Bypass -File kaoyan\tools\dashboard.ps1`
开工前先 `Get-Date -Format "yyyy-MM-dd HH:mm dddd"` 取真实时间，再排任何钟点。

三条口径：
- 完成度按交付物算（章节或讲次、题号区间、正确率、用时）。
- 每天三查：早启动 → 中检 → 晚复盘。
- 写进 `logs/` 才算数。

---

## 协议 A · 早启动

1. 读 `state.yaml`、当前阶段、最近两天日志。
2. 跑看板，取倒计时与近 7 日各科时长。
3. 写 `kaoyan/state/今日作战单.md`，只有三块：
   - **1. 今天推进什么**：3-4 条，具体到章节或小节、题量、验收方式。
   - **2. 钟点表**：从当前时间排到 21:30，含三餐、傍晚散步、块间休息；块长 60-100 分钟。
   - **3. 当下第一步**：一句话，立刻能动手的那件。
4. 回复给作战单全文，结尾一句「现在去做的第一件事：___（限时 __ 分钟）」。

### 作战单模板

```markdown
# 今日作战单 · 2026-10-27（周二）· D-53

## 1. 今天推进什么
- 线代第 1 章 行列式收尾：例题做完，记正确率
- 数据结构 7.3 树型查找：选择过一遍，错题标号
- 计网 4.3 ICMP：一页事实清单 + 本节习题
- 英语 2012 Text 3：通读，生词进本

## 2. 钟点表
16:00-16:20 休息（刚做完数学，起身走走）
16:20-17:50 数据结构 7.3
17:50-18:30 晚饭
18:30-19:15 出门走，听歌
19:15-20:30 计网 4.3
20:30-20:45 休息
20:45-21:10 英语 2012 Text 3
21:10-21:30 收尾，关屏
23:00 前躺下

## 3. 当下第一步
翻到王道第 7 章 7.3，先做 10 道选择题。
```

## 协议 B · 中检

用户发 iHour 截图、睡眠截图、手写笔记照片，或说「学了一半」时：

1. 先确认产出：哪科、多久、做到哪，一句话说出来。
2. 先取时，看还剩多少，从剩下的块里挑 1-2 件最重要的，其余顺延。
3. 累了或卡住：主动减一块，或换成低阻力科目（英语阅读、背单词、看政治）。
4. 回复不超过 10 行：完成的 + 接下来 1-2 件 + 钟点。结尾给「第一步」。

---

## 协议 C · 晚复盘

1. 一次问完数据：科目 / 材料 / 章节或题号 / 正确率 / 用时。缺的补一句，不反复追问。
2. 写 `kaoyan/logs/<今天>.md`（格式见下），机器可读块写全。
3. **写完跑一次看板**，确认「日志总数」+1；不涨就是格式错，当场改。
4. 更新 `state.yaml` 的 `current_progress`（原地改，不新建日期字段）与 `recent_sleep`（只留最近 5 天）。
5. 错题按需追加到 `kaoyan/mistakes/mistakes.md`。
6. 回复三段：今天做了什么 / 卡在哪 / 明天第一件事。不超过 15 行。

---

## 协议 D · 周复盘

1. 跑看板取近 7 日数据。
2. 四个子代理并行分析（数学 / 408 / 英语 / 政治），各自读近 7 天日志与计划对应章节。
3. 汇总成：本周交付表、偏差原因（材料、顺序、时间分配）、下周 3 条具体动作、里程碑进度。
4. 落后超过两成，转协议 G。

---

## 协议 E · 抽查

总耗时不超过 5 分钟，不额外占用学习时间。

1. 首选：从当天做过的题或错题本里抽 1-2 道，遮答案重做。
2. 次选：让用户口述方法步骤，30 秒级。
3. 只有当天没有可抽的题（纯看课）才自己出题，同源、不超纲。
4. 判分给错因（概念 / 计算 / 审题 / 时间），错题进错题本。
5. 通过标准 80%；没过，这科第二天先回炉 30 分钟。

---

## 协议 F · 崩盘急救

1. 先减负，不追问原因：数学 120 分钟核心例题 + 408 120 分钟选择题 + 英语 1 篇阅读。
2. 政治归零，其余顺延。
3. 只问一个结构性问题：没睡好、任务太多，还是某科卡死？
4. 回复不超过 8 行，以「第一步」结尾。

---

## 协议 G · 阶段重排

原则：砍范围，不砍睡眠。

1. 列出本阶段剩余任务，标必做 / 可缓 / 放下。
2. 砍的顺序：政治强化 → 英语词汇书 → 408 低频细节 → 数学偏题 → 重复题型。
3. 改 `kaoyan/plans/百日总作战计划.md` 对应阶段表，末尾记一行「重排：日期 + 原因 + 砍了什么」。
4. 改 `state.yaml` 的 `milestones`。
5. 一句话讲清：牺牲的是广度，换的是核心题型的正确率。

## 日志格式

```markdown
# 2026-10-27 学习日志

[机器可读]
date=2026-10-27
hours=5.5
math_min=109
cs408_min=165
english_min=25
politics_min=0
math_deliver=线代第1章行列式例题+笔记
cs408_deliver=数据结构7.3选择20题(对16)+计网4.3习题
english_deliver=2012 Text3 通读+生词18
politics_deliver=史纲第5节
sleep_hours=6.6
sleep_at=00:48
mood=7
checkin=complete
[机器可读结束]

## 实际时间线
13:50-15:39 数学 线代第 1 章 行列式例题与笔记

## 卡点
...

## 明日第一件事
...
```

- 块内一律 `key=value`，不是冒号；`hours` 保留一位小数；`checkin` = complete / incomplete。

## 状态文件契约（`kaoyan/state/state.yaml`）

只保留这些键：`meta`、`target`、`current_progress`、`milestones`、`recent_sleep`、`active_preferences`。
复盘时直接改 `current_progress` 的 `done / now / next`，不加日期子字段；历史都在 `logs/` 里。

## 反模式

| 现象 | 纠正 |
|---|---|
| 一天只学一科 | 下午切另一科 |
| 只看课不做题 | 日志必须写正确率，写不出算没完成 |
| 408 只刷选择、回避大题 | 每天 1 道算法或计算大题 |
| 熬夜补时长 | 23:00 睡，缺的白天分两天补 |
| 排表连排、不给吃饭休息 | 补上三餐与起身时间 |
| 只给块不给钟点 | 补到分钟 |
