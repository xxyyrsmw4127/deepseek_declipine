# 第二节　北京地区科研院所 / 央企研究生院计算机类专硕

## 2.0 总体格局（先纠正一个常见误解）

**北京地区招计算机类专硕的科研院所，绝大多数不是「与高校联合培养挂靠招生」，而是「研究院 / 集团研究生院作为独立招生单位自招」，学位由该招生单位（研究院）授予。** 已核实的三个典型：
