### 4.1 单次处罚

| 违反 | **处罚（当天或次日执行）** |

| **R3 情绪评价超一次** | ① 当日剩余时间**取消一切非学习对话**（包括与督学的择校/闲聊/复盘式长对话）；② 只允许报数字 |
| **R4 单块超 120 分钟或全天无任何换通道** | 次日**强制在块间插入 20 分钟出门走路**（写进作战单，不许合并） |

### 4.2 累积处罚（违规次数按自然周统计，周一 00:00 清零）

| 累计（一周内） | 处罚 |
|---|---|
| **1 次** | 单次处罚照执行，不叠加 |
| **2 次** | 次周**首日降级档**（数学 120′ / 408 120′ / 英语 30′ / 政治 0）—— 用减量逼回节奏，不逼加量 |
| **3 次** | 次周**政治归零 + 英语压到 1 篇阅读**，全部时间并入数学与 408（承宪法第 8 条）；并写一份 `state.yaml: flags` 的事故留痕（成因 + 次数 + 损失） |
| **4 次及以上** | **强制执行一个"恢复日"**：次日 14:00 前不排学习（形态等同宪法第 18 条补偿日），且当日**断开与督学的非必要对话**（Agent 只在三次固定检查点出现）。理由：连续违规说明系统性问题，加罚只会加速宕机 |

### 4.3 处罚的三条边界（防止处罚变成新的伤害源）

1. **不许罚时长**（不许"罚多学 1 小时"）—— 罚时长 = 从睡眠或次日的产能里借，是负收益。
2. **不许罚睡眠**（不许"罚少睡"）—— 睡眠是一级 KPI，任何处罚都不得触碰 06:30 起床与 23:00 合眼这两端。
3. **不许人格化**（不许出现"你怎么又这样"）—— 只记事实、只执行处罚动作，不评价人。

## 八、强制休息日（R19，10/21 用户裁定）

> 用户原话：「频率：11天；形态：半天，但允许上半日下半日的自由安排，而且必须是完全坦然接受休息状态；日期：11天间隔强制执行」。
> 依据：耗尽型归零实测间隔 = 10/8→10/21（13 天 / 12 个作战日），上一次 9/29→10/7（9 个作战日）→ **耐受上限 10-12 个作战日**，11 天是留 1-2 天余量的取值。

| 参数 | 裁定 |
|---|---|
| **频率** | **11 天间隔，强制执行**。**不得延后**；可提前，但不得早于第 8 天 |
| **形态** | **半天**。上半日 / 下半日 **当天早上自选**：上半日 = 12:00 前不排学习块；下半日 = 13:30-17:30 不排学习块 |
| **坦然接受** | 休整日里「我应该学」不是他的问题，是排程的问题。agent 当天**不得**：提倒计时/余额/欠账、建议「顺手做点」、问「要不要学一点」、在作战单里给休整半日排灰色任务 |
| **记账** | 日志写 `rest_day=planned`；**不计断链、不触发宪法第 8 条、不算未达保底、不进 backlog** |
| **执行方式** | 不靠 agent 记性，靠作战单：每张作战单首行写「**距强制休整日：N 天（上限 M/D）**」 |

**当前排期**：起点 = **2026-10-21**（当日被动归零，身体已歇）→ **上限 11/1（周日）**；可提前窗口 **10/29-11/1**。**越接近 11/1 越接近崩线**（实测 12 个作战日必崩）→ 建议落在 **10/29-10/30**。

**与宪法第 18 条补偿日的区别**：补偿日 = **睡眠债**触发的被动休整（S≥7 且 D≥3）；R19 = **连续作战时长**触发的主动休整。两者可叠加，但同日只消耗一次 —— 同一天既触发 R19 又触发补偿日时，按 R19 执行，补偿日权益**保留不消耗**。
