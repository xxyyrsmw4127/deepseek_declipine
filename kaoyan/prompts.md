# 督学口令 · 直接复制粘贴到 DSH 会话

> 会话工作区 = `D:\deepseek_dsh`，`AGENTS.md` 与 `kaoyan-supervisor` skill 会自动生效。
> 每天只需复制 **3 条**（开工 / 中检 / 收工）；周日多一条周复盘。

---

## 0. 首次校准（只做一次，3 分钟）

```
校准基线。读 kaoyan/state/state.yaml 的 baseline，然后问我 4 个问题（数学进度 / 408 进度 / 英语真题情况 / 每天可用时段），
我答完后你回填 state.yaml 并重写 kaoyan/state/今日作战单.md。
```

## 1. 开工（每天 08:00 前后）

```
开工。按协议 A 执行：读 state.yaml + 当前阶段 + 最近日志，跑 dashboard.ps1，
然后写今日作战单（每块写明具体讲次/题号），最后给我「现在去做的第一件事」。
```

极简版：`开工`

## 2. 中检（12:00 或 15:30）

```
中检。现在 <时间>，上午交付到 <题号/讲次>，卡在 <知识点/走神/材料>。
按协议 B 判断偏差，告诉我下一个 45 分钟只做什么。
```

极简版：`中检：上午只做到第 2 讲，卡在中值定理`

## 3. 收工复盘（每天 21:30）

```
收工。按协议 C 执行：我报数据，你写 kaoyan/logs/<今天>.md、更新 state.yaml、抽查 3-5 题。
今天数据：数学 <分钟> / 408 <分钟> / 英语 <分钟> / 政治 <分钟>；交付物 <讲次/题号/正确率>。
```

极简版：`收工：数学240 408180 英语45 政治30`

## 4. 周复盘（每周日 20:00）

```
周复盘。按协议 D 执行：跑 dashboard.ps1，用 4 个子代理并行分析数学/408/英语/政治，
汇总出偏差表 + 结论 + 下周作战单 + 里程碑达成情况。
```

## 5. 抽查（任意时间，一天最多 2 次）

```
抽查我。按协议 E 出题：数学 2 题 + 408 3 题，限时 <分钟数>，我做完你判分并入错题本。
```

极简版：`抽查 408`

## 6. 崩盘急救（情绪崩了 / 进度废了）

```
我崩了。按协议 F 执行：今天只保底线，其余全部砍掉写进 backlog，别安慰我，直接告诉我现在做什么。
```

## 7. 计划重排（偏差 >20%，或某阶段结束）

```
重新排计划。按协议 G 执行：给我当前阶段的剩余任务分级（必做/可砍/延期），
砍掉的是哪些，里程碑怎么移动，然后重写 kaoyan/plans/百日总作战计划.md 的对应阶段表。
```

## 8. 状态速查（任何时候）

```
报当前态势：倒计时、阶段、本周目标进度、欠账、连续达标天数、最大风险。
```

## 附：口令与协议的对应关系

| 口令 | 协议 | 产物 |
|---|---|---|
| 开工 | A | 重写 `kaoyan/state/今日作战单.md` |
| 中检 | B | 会话内回复（必要时起后台番茄钟） |
| 收工 | C | 新建 `kaoyan/logs/<日期>.md` + 更新 `state.yaml` + 追加 `mistakes.md` |
| 周复盘 | D | 4 个子代理分析 + 更新 `state.yaml`，必要时重排 |
| 抽查 | E | 判分 + 追加 `kaoyan/mistakes/mistakes.md` |
| 崩盘 | F | 最小任务 + `backlog` + `flags.mode: degraded` |
| 重排 | G | 改写 `kaoyan/plans/百日总作战计划.md` + 里程碑顺延 |
