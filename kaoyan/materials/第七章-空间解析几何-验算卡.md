## 一、曲面族标准方程（只记「方程 ↔ 名称 ↔ 图形」三件事）

| 名称 | 标准方程 | 备注 |
|---|---|---|
| 球面 | $(x-a)^2+(y-b)^2+(z-c)^2=R^2$ | 球心 $(a,b,c)$，半径 $R$ |
| 椭球面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2}=1$ | 三项全正、右边为 1 |
| 椭圆锥面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=0$ | 齐次式（无常数项）→ 过原点 |
| 椭圆抛物面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=z$ | 两个平方项同号，另一变量为一次 |
| 双曲抛物面（马鞍面） | $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=z$ | 两个平方项异号 |
| 单叶双曲面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=1$ | 右边 +1，三系数两正一负 |
| 双叶双曲面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=-1$ | 右边 −1 |
| 椭圆柱面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$ | 缺 $z$ → 母线平行 $z$ 轴 |
| 抛物柱面 | $y^2=2px$ | 同上，缺一个变量即柱面 |

**判断口诀（1 秒分流）**：① 有几个变量平方 → 缺一个 = 柱面；② 有没有一次项 → 有 = 抛物面；③ 有没有常数项 → 没有 = 锥面；④ 平方项同号 = 椭圆型，异号 = 双曲型。

## 二、旋转曲面（数一小題常客，第二十四/二十五节）

| 情形 | 旋转轴 | 方程写法 |
|---|---|---|
| 曲线 $f(y,z)=0$ 绕 **$z$ 轴** | $z$ | $f(\pm\sqrt{x^2+y^2},\;z)=0$ |
| 曲线 $f(y,z)=0$ 绕 **$y$ 轴** | $y$ | $f(y,\;\pm\sqrt{x^2+z^2})=0$ |
| 母线含哪个变量 | — | **绕谁转，谁不变；另一个变量换成 $\pm\sqrt{\text{剩下两个的平方和}}$** |

**易错点**：母线方程里出现两个变量，**没出现的那个变量就是旋转轴**；换的时候是「平方和开根」，不是「把那两个变量各换一遍」。

## 三、向量与平面/直线常用式（9/30 已产出的部分，此处仅为验算留痕）

| 项 | 公式 |
|---|---|
| 模 / 方向余弦 | $\lvert\mathbf a\rvert=\sqrt{a_x^2+a_y^2+a_z^2}$；$\cos\alpha=\dfrac{a_x}{\lvert\mathbf a\rvert}$ |
| 数量积 | $\mathbf a\cdot\mathbf b=a_xb_x+a_yb_y+a_zb_z$；$\mathbf a\perp\mathbf b\Leftrightarrow\mathbf a\cdot\mathbf b=0$ |
| 向量积 | $\mathbf a\times\mathbf b=(a_yb_z-a_zb_y,\;a_zb_x-a_xb_z,\;a_xb_y-a_yb_x)$；$\mathbf a\parallel\mathbf b\Leftrightarrow\mathbf a\times\mathbf b=\mathbf 0$ |
| 混合积 / 平行六面体 | $(\mathbf a\mathbf b\mathbf c)=\mathbf a\cdot(\mathbf b\times\mathbf c)$；$V=\lvert(\mathbf a\mathbf b\mathbf c)\rvert$ |
| 四面体体积 | $V=\dfrac16\lvert(\mathbf a\mathbf b\mathbf c)\rvert$ |
| 三向量共面 | $(\mathbf a\mathbf b\mathbf c)=0$ |
| 平面（点法式） | $A(x-x_0)+B(y-y_0)+C(z-z_0)=0$，法向 $\mathbf n=(A,B,C)$ |
| 直线（对称式） | $\dfrac{x-x_0}{m}=\dfrac{y-y_0}{n}=\dfrac{z-z_0}{p}$，方向 $\mathbf s=(m,n,p)$ |
| 线面关系 | $L\parallel\pi\Leftrightarrow \mathbf s\cdot\mathbf n=0$；$L\perp\pi\Leftrightarrow \mathbf s\parallel\mathbf n$ |
| 线面角 | $\sin\varphi=\dfrac{\lvert\mathbf n\cdot\mathbf s\rvert}{\lvert\mathbf n\rvert\lvert\mathbf s\rvert}$ |
| 点到平面距离 | $d=\dfrac{\lvert Ax_0+By_0+Cz_0+D\rvert}{\sqrt{A^2+B^2+C^2}}$ |

## 四、昨日已确认的待补边界（10/4 回炉，1 道题）

> 用比例式 $\dfrac{a_x}{b_x}=\dfrac{a_y}{b_y}=\dfrac{a_z}{b_z}$ 判平行，**只要有一个分量为 0，比例式即失效**（0 不能作分母）→ 统一改写为 $\mathbf a\times\mathbf b=\mathbf 0$。这是数一真题设坑点。
