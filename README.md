## 3 分钟上手

1. **回填基线（只做一次）**：打开会话，粘贴 `kaoyan/prompts.md` 里的「0. 首次校准」。
2. **每天早上 08:00**：新建会话 → 说 `开工` → 拿到当天作战单。
3. **每天 21:30**：说 `收工：数学240 408180 英语45 政治30` → 它会写日志、更新状态、抽查你 3-5 题。
4. **每周日 20:00**：说 `周复盘` → 4 个子代理分科分析 → 下周作战单。
5. 崩了就说 `我崩了`，计划来不及了就说 `重新排计划`。

看板（随时）：
```
kaoyan\tools\dashboard.cmd
```

## 三条不许破的规则

1. **落盘即事实**：没写进 `kaoyan/logs/` 的学习等于没发生。
2. **保底线**：数学 180 min + 408 180 min / 天。砍任务只砍范围，不砍时长。
3. **零虚构**：不补写日志、不美化进度。看板好看而数据假 = 这套系统失效。
